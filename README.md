# ELFY — Headless Shopify Malaysia Storefront

Luxury sartorial menswear & horology headless storefront for Malaysia market.

- **Brand**: ELFY Kuala Lumpur (`ELFY Goods`)
- **Domain**: `elfy.my` (`https://elfy.my`)
- **Worker**: `https://elfy.ongki.workers.dev`
- **Shopify Store**: `vvxgev-3p.myshopify.com` (Storefront API `2025-01`)
- **Stack**: Astro 5 (Server SSR), React Islands, Tailwind CSS v4, TypeScript, Cloudflare Workers

## Commands

```bash
pnpm dev       # Local development server
pnpm build     # Build for Cloudflare Workers
pnpm cf:ship   # Deploy to Cloudflare Workers
```
